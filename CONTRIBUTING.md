# Contributing

Thank you for your interest in contributing.

## Reporting Issues

- Search first for an existing issue about the same subject.
- Describe the expected and the observed behavior, with steps to reproduce.

## Sending Changes

1. Fork the repository and create a descriptive branch, such as `fix/...` or
   `feature/...`.
2. Make small commits with clear messages.
3. Run the project's tests and formatter before submitting.
4. Open a pull request explaining what changes and why.
5. A maintainer will review it and may ask for adjustments.

## Style

Follow the style of the existing code and keep the pull request focused on a
single change.
